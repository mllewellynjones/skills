# Roadmap

## Next up

- **decision-deep-dive** — a structured decision-making process for reaching a clear, committed decision on situations with real trade-offs, documenting it, and stopping.
- **project-setup** (working name; currently project-intake) — classify a new project as Execution, Strategic Bet, or Decision, then run the matching setup workflow.

## Planned

- **prepare-handover** — summarise the current conversation into a handover (in chat or as a markdown file) so a fresh conversation can pick up with full context; designed for approaching context-window limits.
- **frame-hypothesis** — turn a problem statement (after questioning the statement itself) into a proposed hypothesis, then break it into a MECE issue tree that can be used to test it.
- **question-with-doc** — use a document or specification as grounding, then interrogate the author to fill gaps, sharpen detail, and remove contradictions and unstated assumptions.
- **break-into-packets** — decompose a large piece of work (typically a refined specification) into smaller packets: workstreams for a consulting case, or GitHub issues for a build.

Some locally-used skills are deliberately not published here — they are coupled to a personal productivity setup and would not generalise.
